# Google Material Design 3 (M3 / Material You)

> Source: https://m3.material.io/ | https://m3.material.io/styles | https://m3.material.io/tokens

## Core Principles (2–3 sentences)
Material Design 3 ("Material You") is Google's adaptive design system built around **dynamic colour** — the interface derives its palette from the user's wallpaper via the Monet algorithm. It replaces static brand colours with **tonal palettes** (six tones per hue) and uses **elevation through tonal surface overlays** rather than drop shadows. The system is component-token-first: every visual property is a semantic token, never a hardcoded value.

---

## Color System

M3 generates a full palette from a single **source colour** using the HCT (Hue-Chroma-Tone) colour space.

### Tonal Palette Structure
Each key colour produces a **13-stop tonal palette** (0, 4, 6, 10, 12, 17, 20, 22, 24, 30, 40, 50, 60, 70, 80, 87, 90, 92, 94, 95, 96, 98, 99, 100).

### Semantic Colour Roles
| Token | Light default | Dark default | Usage |
|---|---|---|---|
| `primary` | tone 40 | tone 80 | Key actions, active states |
| `onPrimary` | tone 100 | tone 20 | Text/icon on primary |
| `primaryContainer` | tone 90 | tone 30 | Tonal button fill, selected chips |
| `secondary` | tone 40 | tone 80 | Supporting colour |
| `surface` | tone 98 | tone 6 | Page/app background |
| `surfaceVariant` | neutral-variant 90 | neutral-variant 30 | Cards, sheets |
| `surfaceContainer` | tone 94 | tone 12 | Containers |
| `surfaceContainerHigh` | tone 92 | tone 17 | Elevated containers |
| `outline` | neutral-variant 50 | neutral-variant 60 | Borders, dividers |
| `error` | `#B3261E` | `#F2B8B5` | Error states |

### Dark Mode
Dark mode uses higher tone numbers for background roles and lower for foreground. M3 does **not** simply invert — it re-maps every role using the HCT palette. Never manually darken/lighten colours; always use the token for the role.

### Dynamic Colour
Wrap the root in `MaterialTheme` (Compose) or use CSS custom properties generated by the [Material Theme Builder](https://material-foundation.github.io/material-theme-builder/).

## Spacing & Layout Grid

- **Base unit:** 8dp
- **Spacing token:** `space100` = 8dp; scale: 4, 8, 12, 16, 20, 24, 28, 32, 36, 40, 48, 56, 64...
- **Layout grid:** 4-column (compact ≤599dp), 8-column (medium 600–904dp), 12-column (expanded ≥905dp)
- **Column gutter:** 16dp (compact), 24dp (medium/expanded)
- **Content max-width:** 1240dp (expanded, with 200dp margins)

## Elevation Model

M3 uses **tonal surface colour overlays** for elevation, NOT drop shadows (on surfaces).
Shadows are used only on certain floating components (FAB, dialogs, menus).

| Level | Overlay opacity | Component examples |
|---|---|---|
| 0 | 0% | Surface, background |
| 1 | 5% | App bar (scrolled), nav rail |
| 2 | 8% | FAB (resting) |
| 3 | 11% | FAB (hover) |
| 4 | 12% | Bottom nav (scrolled) |
| 5 | 14% | Dialog, menu |

Shadow tokens (for floating components):
- `elevation1`: `0 1px 2px rgba(0,0,0,0.3), 0 1px 3px 1px rgba(0,0,0,0.15)`
- `elevation2`: `0 1px 2px rgba(0,0,0,0.3), 0 2px 6px 2px rgba(0,0,0,0.15)`
- `elevation3`: `0 4px 8px 3px rgba(0,0,0,0.15), 0 1px 3px rgba(0,0,0,0.3)`

> **Conflict note:** Requests for heavy card shadows under M3 are spec violations. Use `surfaceContainer` tonal elevation instead. Offer the shadow as a deviation option.

## Corner Radius Conventions

| Shape token | Value | Component examples |
|---|---|---|
| `shapeExtraSmall` | 4dp | Chip, tooltip |
| `shapeSmall` | 8dp | Text field, menu item |
| `shapeMedium` | 12dp | Card, dialog, modal |
| `shapeLarge` | 16dp | Navigation drawer, bottom sheet |
| `shapeExtraLarge` | 28dp | FAB, large card hero |
| `shapeFull` | 50% | FAB (circular), avatar, badge |

Buttons: Filled = `shapeFull` (pill). Tonal/outlined = `shapeFull`. Icon-only = `shapeFull`.

## Motion Principles

M3 uses the **Expressive Motion** system — physics-informed spring animations.

| Category | Easing | Duration |
|---|---|---|
| Emphasized (standard) | `cubic-bezier(0.2, 0, 0, 1)` | 500ms |
| Emphasized decelerate (enter) | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 400ms |
| Emphasized accelerate (exit) | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 200ms |
| Standard (utility) | `cubic-bezier(0.2, 0, 0, 1)` | 300ms |
| Standard decelerate | `cubic-bezier(0, 0, 0, 1)` | 250ms |
| Standard accelerate | `cubic-bezier(0.3, 0, 1, 1)` | 200ms |

Transitions use **shared axis** (page transition), **fade through** (tab switch), **container transform** (detail expand).

## Iconography

- **Library:** [Material Symbols](https://fonts.google.com/icons) — variable font icons
- **Styles:** Outlined, Rounded, Sharp — always use one style throughout the app
- **Weights:** Variable weight axis 100–700; `FILL` axis 0–1 (filled vs outlined)
- **Size:** 24dp default; minimum 20dp; never below 18dp
- **Optical size axis (`opsz`):** Set to match the icon display size

Web import: `<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined" rel="stylesheet">`

## 5 Signature "Tells" — Unmistakably Material 3

1. **Pill-shaped filled buttons** — `border-radius: 9999px`, filled with `primary` tonal colour
2. **Tonal elevation** — cards lift via a slightly-tinted `surfaceContainerHigh` background, zero drop shadow
3. **Large expressive headlines** — `displayLarge` (57sp) for hero headlines with tight negative tracking
4. **Dynamic colour palette** — palette derives from brand/wallpaper seed; no static #hexcodes
5. **Continuous corner radius** — every container has generous rounding (12–28dp); nothing has sharp corners
